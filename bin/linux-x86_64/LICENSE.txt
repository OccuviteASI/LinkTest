  https://github.com/esnet/iperf/blob/master/LICENSE
  Static (musl) build by userdocs: https://github.com/userdocs/iperf3-static
  The build is statically linked against musl libc (MIT licence,
  https://musl.libc.org/) and needs no shared libraries.

LinkTest itself contains no code from iperf3; it runs the binary as a separate
process and reads its output.
